# bot 模板

一个文件一个模板，文件里只放设定正文，建 bot 时整段贴进描述。本页是说明，不参与核对。

| 模板 | 文件 | 名称格式 | 类型 | 必要应用 | 可选应用 | 定时任务 |
|---|---|---|---|---|---|---|
| 参谋长 | `chief-of-staff.md` | 参谋长 | 参谋长 | Notion、GitHub（bot 电脑命令行授权，读写本项目仓库） | Slack（巡检和复盘通知） | 三个：每日扫描、工作日巡检、每周一复盘（见 skill「参谋长治理」第 0 节） |
| 副官 | `deputy.md` | 副官·〈项目名〉 | 副官 | Notion | 按项目：GitHub（写代码）、Cloudflare（部署）、Figma（设计）、Slack（通知） | 每日扫描（副官守则要求首次对话自己建，见 skill「通用流程」第 0 节） |
| 专职·流程QA | `qa.md` | 专职·流程QA | 专职，共用、不绑项目 | Notion（只读 A 表、P 表和交付物；写权限无法按 bot 隔离，靠自律与机械检测） | 无 | 无 |
| 专职·想法挑刺 | `idea-critic.md` | 专职·想法挑刺 | 专职，共用、不绑项目；原型 Product Idea Stress Test | 无（只用联网搜索） | 无 | 无 |
| 专职 bot 通用规矩 | `specialist-common.md` | — | 不单独建 bot | — | — | — |

- **占位**：`deputy.md` 里的「〈项目名〉」建 bot 时换成实际项目名。核对时只做这一处替换。
- **项目专有补充**：`deputy.md` 最后一行是「【项目专有补充】」。这一行之后可以接本项目的领域知识、语气、用户偏好和项目专有规矩，新建的副官留空。核对只比到这一行为止，补充段归项目所有，改动由副官记进本项目 D 表（中等变更），用户确认。
- **专职 bot 通用规矩**：参谋长新写专职 bot 时放在设定正文末尾；从模板库导入的专职 bot，经用户批准后由参谋长追加到它的设定正文末尾。模板库导入的保留原名。
- **专职·想法挑刺**：用户个人情况放共享记忆，不写进设定正文。它和无上下文红队评审不合并：想法挑刺要用户上下文并长期存在；红队评审由发起方每次开无上下文临时子任务，不建 bot。
- **副官和参谋长**：设定正文只写定位，规矩在 skill「通用流程」第 0 节「副官守则」（参谋长另加 skill「参谋长治理」第 0 节「参谋长守则」）。专职 bot 的设定正文就是它的全部核心规矩。
- 建 bot、名册登记、升级见 skill「参谋长治理」第 4c、7 节。
