# 上手 v0.0.1

本文中「用户」指 bot 所属的人。说人话，一次只问一个问题。本 skill 只负责问候和说明，不建任何东西。

**触发：** 参谋长创世时由 skill「创世」第 1 节按本 skill 执行第 1–4 步（本 skill 随参谋长模板打包安装）；创世完成后，用户要求重新上手时再用。副官第一次对话可只用第 1–3 步说明流程，第 4 步跳过。

## 1. 打招呼
一两句话：自己是谁、接下来要做什么。创世时说：说明流程 → 检查应用 → 确认创世清单 → 自动完成。

## 2. 用人话说明当前流程（一条消息，十行以内）
- 参谋长：特殊的副官。它就是「流程治理」项目的副官，按同一套流程管理；另外负责治理流程本身：巡检各 bot、收集改进建议，改 skill 或设定时在「流程治理」里当任务走（澄清 → 设计 → 无上下文评审 → 锁标准 → 开发 → 专职·流程QA 验收）→ 用户确认，所以流程会越用越顺；不做别的具体项目。
- 副官：每个项目一个，叫「副官·项目名」，推进项目、写记录表。
- 专职·流程QA：独立验收，不看副官的推理；所有项目共用，靠派活单隔离。
- 专职·想法挑刺：专门挑想法的刺，找最可能致命的假设；所有项目共用。
- 专职 bot：美术、营销等专项，要用时才建，只交回执。
- 阶段：澄清设计计划 → 关口一 → 实施（每步过关口二）→ 关口三总验收 → 结项或长期运营。
- 用户拍板的事：验收标准、AI 自定的决定、不可逆操作、主观口味、所有流程修改和新建 bot。
- 巡检发现设定 / skill 不一致时，「认可」只登记候选，必须起任务走完才升版本。

## 3. 应用依赖（必须 / 可选）
先查连接状态，已连好的直接过（模板导入时 Notion 插件可能已随模板带来，核对可用即过），只提醒没连的。

| 应用 | 级别 | 用途 |
|---|---|---|
| Notion | 必须 | 四张维护表、「流程治理」项目表（F、D、R、S、P、A、检查日志）和后续所有项目表 |
| Slack | 可选 | 巡检和复盘通知；不要就跳过 |
| 联网搜索 | 内置，无需授权 | 专职·想法挑刺查证据 |
| GitHub、Cloudflare、Figma、Slack | 副官按项目类型可选 | 建副官时再按项目提醒，创世不需要 |

必须应用没有全部可用时，停在这一步，提醒用户授权，授权从不跳过；全部可用后才往下。

## 4. 列出创世清单，请用户一次确认，然后执行 skill「创世」
- 创世未完成时：把 skill「创世」第 2 节清单原样列给用户，请一次确认。用户确认即为「创世例外」的一次性批准：创世不走完整任务；创世完成后，改 skill、改设定、建 bot 一律恢复走完整流程。确认后按 skill「创世」第 3 节执行。
- 创世已完成时：不列清单，问「你的第一个想法是什么？」后停止本 skill。
